# Non-delayed construction-order witness

The strongest construction-order results were first developed on delayed-copy
and delayed-repeat sources. That family is analytically convenient, but it risks
making the phenomenon look specific to literal delay lines.

This note freezes a small counterexample to that interpretation.

## Generic second-order Markov language

Let the observable source state be the last two emitted bits,

```text
00, 01, 10, 11
```

with next-token probabilities

| suffix | P(next=1) |
|---|---:|
| 00 | 0.1 |
| 01 | 0.8 |
| 10 | 0.6 |
| 11 | 0.2 |

and the ordinary shift update after each emitted bit.

This is a generic binary order-2 Markov language. It is not generated by the
delayed-copy/repeat rule used in the earlier theorem family.

## Pattern-recognition memory

Use three memory states. Memory 0 is the collapsed state. A useful computation
recognizes suffix `01`:

```text
0 --0--> 1 --1--> 2
```

Memory states 0 and 1 use the uniform decoder. Memory state 2 uses

```text
P(next=0)=0.2
P(next=1)=0.8
```

which matches the source prediction after suffix `01`.

Give the two missing routing links independent probabilities

\[
\varepsilon_1,\varepsilon_2.
\]

At the collapsed point, memory never leaves state 0 and the finite-horizon loss
is exactly

\[
L_0=\log 2.
\]

For horizon `T=12`, the exact multivariate finite-horizon polynomial has

\[
\boxed{
L-L_0
=-0.022945804407352086\,
\varepsilon_1\varepsilon_2
+O(\|\varepsilon\|^3).
}
\]

Both linear coefficients vanish. Thus the first useful derivative is genuinely
second order even though the source is unrelated to delayed repeat.

## Dormant prewiring

Now change only the behaviorally unreachable topology: prewire the downstream
transition

```text
1 --1--> 2
```

while keeping the entrance transition from memory 0 absent.

The current predictor is unchanged because memory state 1 remains unreachable.
The initial loss is still exactly `log(2)`. The eventual fully wired controller
is also exactly the same transition function as before.

But only the entrance probability remains trainable. The exact loss polynomial
now begins

\[
\boxed{
L-L_0
=-0.022945804407352086\,
\varepsilon_1
+O(\varepsilon_1^2).
}
\]

So the same current predictor, same architecture, same decoder, same eventual
useful computation, and same leading predictive coefficient realize

\[
\boxed{
2\text{nd-order accessibility}
\rightarrow
1\text{st-order accessibility}
}
\]

solely because of dormant unreachable topology.

## What this establishes

### Exact / regression-tested

- the collapsed predictors are identical;
- both initial losses are `log(2)`;
- the fully activated transition controller is identical;
- the unscaffolded parameterization has leading multivariate degree 2;
- the dormant-prewired parameterization has leading degree 1;
- the leading useful coefficient is the same in both parameterizations.

### What it does not establish

This one fixture does not prove that every higher-order stochastic language has
an arbitrary construction-order spectrum. It only removes literal delayed-copy
structure as a necessary ingredient for the basic functional-equivalence order
phenomenon.

## Consequence for framing

The construction-order story should therefore be framed around **how a useful
finite-memory computation is assembled in parameter space**, not around delay
lines specifically. Delayed sources remain the clean theorem family; this
second-order Markov witness shows the mechanism survives on a qualitatively
different predictive language.
