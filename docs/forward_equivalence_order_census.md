# Accessibility-order diversity inside one forward-equivalence class

The dormant forward-equivalence theorem proves that rewiring transition rows that
the source-memory product process cannot exercise leaves the entire current
finite-horizon forward process unchanged. The construction-order theorem predicts
that those same dormant zero-cost edges can nevertheless alter the number of
perturbative edits required to reach an informative readout class.

The deterministic scaffold family realizes this effect at every prescribed order.
This audit asks a more adversarial question:

> if we randomize dormant topology rather than hand-designing a prefix scaffold,
> does a single exact forward-equivalence class naturally contain a broad spectrum
> of accessibility orders?

The answer is yes on the frozen finite family below.

## One fixed forward-equivalence class

Every one of the 1,000 sampled controllers uses exactly the same:

- two-state persistent visible Markov source with switch probability `0.1`;
- six memory states;
- initial memory state zero;
- reachable state-zero transition rows;
- decoder: memories `0..4` uniform and memory `5` predicts `(0.9, 0.1)`;
- five trainable transition directions;
- horizon `T=10`.

The reachable base controller is always

\[
0\xrightarrow{x}0
\]

for both symbols, so no sampled base controller ever leaves memory zero.
Consequently every sample has the identical current source-memory occupancy and
identical current predictor.

The five trainable directions are also held fixed:

- parameter 1 can enter dormant state `1` after token zero;
- parameters `2..5` can construct the chain links
  \(1\to2\to3\to4\to5\).

Only base transition rows inside dormant memories `1..4` are randomized.

## Random dormant topology

For every intermediate dormant state `i`, independently with probability `0.45`,
we install a zero-cost acyclic skip edge to one uniformly sampled later state

\[
j\in\{i+1,\ldots,5\}.
\]

That row sends probability `0.5` to `j` and `0.5` back to reset. Otherwise the
row remains fully collapsed to reset. Both symbol-conditioned rows receive the
same dormant wiring.

Because state zero is never rewired, every sample is certified by
`is_source_horizon_dormant_rewire` to lie in the **same exact finite-horizon
forward-equivalence class**.

The experiment is generated by

`experiments/forward_equivalence_order_census.py`

with NumPy seed `20260830`. It remains outside CI by design.

## Frozen 1,000-sample result

The exact construction-order oracle returned:

| order triple `(support, operator, loss)` | count |
|---|---:|
| `(1, 1, 1)` | 235 |
| `(2, 2, 2)` | 282 |
| `(3, 3, 3)` | 244 |
| `(4, 4, 4)` | 155 |
| `(5, 5, 5)` | 84 |

with

\[
\boxed{0\text{ non-dormant rewires}}
\]

and

\[
\boxed{0\text{ hierarchy violations}.}
\]

Thus all five derivative orders occur with nontrivial frequency while the current
forward process, decoder, trainable directions, architecture, source, and horizon
are fixed.

This is stronger than pooling many unrelated random controller families: the only
sampled variable is behaviorally dormant base topology.

## Why the order varies

After the learned entrance edge reaches state `1`, a sampled zero-cost dormant
skip may jump over one or more of the otherwise missing trainable chain links.
The source-aware support cost therefore depends on the shortest mixed path made of

- zero-cost sampled dormant base edges, and
- unit-cost fixed trainable directions.

For example, the frozen run contains patterns where a zero-cost route from state
`1` reaches the final informative state, giving order one, and patterns with no
zero-cost skips at all, giving order five.

For the generic fixed decoder used here, every sampled support order is visible in
the quotient construction operator and scalar loss, so

\[
\boxed{
d_{\rm support}=d_{\rm operator}=d_{\rm loss}}
\]

in all 1,000 samples.

This agrees with the analytic genericity result while retaining the separate
hand-tuned cancellation fixtures that show equality is not universal.

## Scientific implication

The census directly falsifies a simple alternative explanation of the earlier
chain results: the accessibility spectrum is not an artifact of choosing a
carefully ordered prefix scaffold.

Inside one forward-equivalence class, random dormant graph structure alone
produces a broad distribution of derivative construction orders.

Combined with the exact construction-time law, the same current predictor can
therefore sit next to local construction mechanisms with qualitatively different
small-initialization bootstrap behavior:

- degree one: finite limiting construction time;
- degree two: logarithmic divergence;
- degree three and above: polynomial divergence with exponent `d-2` in the
  isolated leading-route regime.

The census itself is not a theorem about the distribution of orders under any
universal random graph ensemble. Its role is independent exact-family validation
of the structural theorem.

## Prior-art boundary

Same-function neural-network embeddings through inactive units or inactive
propagation are known to create different flat/saddle landscape geometry, and
parameterization-dependent optimization is broadly established. Those facts make
"same function, different optimization" too broad to serve as a novelty claim.

The narrower finite-memory result tested here is:

\[
\boxed{
\text{with source, current forward process, decoder, architecture, and trainable
transition directions fixed, changing only behaviorally dormant zero-cost wiring
can change the exact first useful derivative order.}
}
\]

That topology-to-construction-order statement is the project-specific claim.
