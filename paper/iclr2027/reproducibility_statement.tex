\section*{Reproducibility Statement}

The central finite-memory results are supported by exact finite-horizon polynomial calculations and regression tests rather than by stochastic large-model training. The public research repository contains the source implementations, exact theorem fixtures, adversarial counterexamples, and a claim-to-code provenance table mapping each headline statement to its corresponding test or experiment. The complete test suite is run in continuous integration. In particular, regressions cover the construction-order hierarchy, dormant forward equivalence, affine and softmax-boundary construction dynamics, regular reparameterization behavior, the independent linear state-space validation, and near-degeneracy counterexamples. The four main figures are generated by a deterministic script and are themselves covered by a headless render smoke test.

Two broader evidence programs are kept outside CI by design: a frozen 1,000-controller census within one exact forward-equivalence class and the illustrative linear-state-space optimization audit. Their seeds/configurations and expected headline outputs are frozen in the repository release checklist. A submission release records the exact repository commit, software environment, test command, evidence commands, and figure-generation command so that algebraic correctness is separated from breadth evidence. Full proof details and experimental protocols are provided in the appendices.
