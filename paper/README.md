# Paper workspace

This directory contains the submission-facing state of the project.

## Authoritative files

- **`manuscript.md`** — canonical current manuscript.
- **`references.bib`** — canonical bibliography.
- **`appendix.md`** — assembled proof supplement for the finite-memory polynomial machinery, construction-order hierarchy, dormant forward equivalence, and visibility-versus-descent distinction.
- **`appendix_dynamics.md`** — assembled dynamics supplement covering affine monomial flow, regular/singular parameterizations, rare-edge softmax geometry, and smooth linear-SSM validation.
- **`appendix_map.md`** — allocation of the remaining exact results into appendices.
- **`reproducibility_matrix.md`** — claim-to-code/test/experiment provenance.
- **`submission_gap_audit.md`** — adversarial assessment of remaining scientific
  and presentation gaps.
- **`release_checklist.md`** — clean-checkout, evidence, figure, bibliography, and
  submission-build procedure.
- **`conceptual_taxonomy.md`** — capacity/behavior/visibility/descent/time
  distinctions and recommended terminology.

Specialized derivations remain under `docs/`; exact implementations are under
`src/memory_frontier/`; CI regressions are under `tests/`; exhaustive or
presentation-level analyses are under `experiments/`.

## Main paper thesis

The project studies the separation

\[
\boxed{\text{forward equivalence does not imply accessibility equivalence}.}
\]

For finite-memory predictors, the local visibility of a latent construction is
decomposed as

\[
\boxed{
d_{\rm support}\le d_{\rm operator}\le d_{\rm loss}.
}
\]

Behaviorally dormant wiring can change these local orders while leaving the
current source-memory forward process unchanged. In the main beneficial fixtures,
the first visible term also provides an admissible descent direction.

The dynamics claim is deliberately metric-aware:

\[
\boxed{
\text{dormant topology}
\to
\text{construction order/local homogeneity}
\to
\text{optimizer geometry}
\to
\text{bootstrap time}.
}
\]

Do not replace this with an optimizer-independent escape-time claim.

## Main figures

The four main figures are generated by:

```bash
python experiments/paper_figures.py --outdir paper/generated_figures
```

The `dev` extra installs Matplotlib, and CI includes a headless smoke test that
requires every main figure to render as both PDF and PNG. Generated binaries are
presentation artifacts and need not be committed during theorem development.

## Reproduction

Core exact regression suite:

```bash
python -m pip install -e '.[dev,optimization]'
pytest -q
```

Main outside-CI evidence:

```bash
python experiments/forward_equivalence_order_census.py
python experiments/linear_ssm_validation.py
```

See `reproducibility_matrix.md` for the source of every headline statement and
`release_checklist.md` for the final submission procedure.

## Scope discipline

The current scientific core is considered closed for manuscript purposes.
Infinite-horizon theory, large neural sequence benchmarks, and general adaptive-
optimizer analyses are follow-up projects unless a concrete correctness or
reviewer requirement makes one necessary for the present paper.
